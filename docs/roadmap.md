# 作業計画

1項目を1コミットの単位とする。`/next-commit` は最初の未完了項目から進める。

- [x] Cursor 用のルールとコマンドを追加
  - 完了条件: `.cursor/rules/`、`.cursor/commands/`、この roadmap がある

- [x] Vite + React + TypeScript の雛形を作成
  - 完了条件: pnpm、Vite、React、TypeScript（strict）、Tailwind CSS、Biome、Vitest の設定があり、空のトップページが表示できる。`.gitignore` がある

- [x] Docker Compose で開発、プレビュー、フォーマット、lint、テストを実行できるようにする
  - 完了条件: `dev`、`preview`、`format`、`lint`、`test` の各サービスが動く。`preview` は GitHub Pages と同じ base パスで動く

- [ ] 設計定数と部材の型を定義
  - 完了条件: マットレス寸法、ダンボール寸法、1x4 の断面と長さ、価格、カット代、カットロスが `src/design/` にある。部材（名前、長さ、本数、3D 上の位置と向き、所属モジュール）を表す型がある

- [ ] 4分割ベースのフレーム設計を作成
  - 完了条件: ダンボールが収まる内寸を満たすモジュール設計が部材データとして定義され、内寸がダンボール寸法と余裕を満たすことをテストで確かめている。設計判断を `docs/design-notes.md` に書いている

- [ ] 木取りと費用の計算を追加
  - 完了条件: 部材リストから 12f 材の必要本数、材ごとの木取り、カット回数、材料費、カット代、合計を計算できる。計算のテストがある

- [ ] 部材リストと費用のページを追加
  - 完了条件: 部材ごとの寸法と本数、購入本数、費用の内訳が表示される

- [ ] カット寸法図を追加
  - 完了条件: 12f 材1本ごとの木取りが SVG で表示され、各部材の長さと端材の長さが読める

- [ ] 組み立て済みの 3D モデルを追加
  - 完了条件: 部材データから 3D モデルを生成し、回転、拡大縮小して見られる。ダンボール箱を収納した状態も表示できる

- [ ] 3D の爆発図を追加
  - 完了条件: 組み立て済みと分解状態をスライダーで切り替えられる。モジュール単位でも分解して見られる

- [ ] GitHub Pages へのデプロイを追加
  - 完了条件: main への push で GitHub Actions が build、lint、test を行い、GitHub Pages に公開される

- [ ] README を整備
  - 完了条件: 公開 URL、ローカルでの起動方法、フォーマット方法、設計の前提が書かれている
