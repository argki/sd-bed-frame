# design

寸法、価格、カットロス、部材の配置、木取り、費用、ネジ止め、モジュール同士のボルト、分解の位置を定義する。画面はここの値を読む。

`constants.ts` に、マットレス、ダンボール箱、1x4、2x4、価格、カットロス、ネジとボルト、脚と根太受けの商品を置く。`types.ts` と `geometry.ts` は、部材の型と直方体の重なりを扱う。`frame.ts` は4分割のフレームと箱の置き場所、`joints.ts` はモジュール内のネジ、`module-joints.ts` は隣のモジュールを留めるボルトである。`cut-plan.ts` と `cut-layout.ts` は 12f 材の木取りとカット図、`materials.ts` は購入するものと費用、`explode.ts` は分解したときの位置である。同じ名前の `*.test.ts` が、これらの計算をテストする。
